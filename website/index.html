常见问题

开始使用前需要知道的事。

NetRelay 支持哪些系统？

当前面向 Windows 10/11 x64，使用 .NET 8 与原生 WPF 构建。

为什么程序需要管理员权限？

启用或禁用 Windows 网络适配器属于系统级操作，因此需要管理员权限。NetRelay 不会借此修改代理、路由表或网络认证配置。

自动切换会不会让我彻底断网？

默认开启安全保护。NetRelay 会在禁用目标网卡前验证备用网络；若备用网络不可用，自动化任务会被跳过并说明原因。

它是 VPN 或代理工具吗？

不是。NetRelay 只管理本机网络适配器状态，不提供 VPN、代理或校园网认证功能。
