# 安全、测试与风险

[上一篇：开发与运维](06-development-and-operations.md) | [返回索引](README.md)

> 当前已有可运行桌面骨架和网卡类型映射单元测试；本文其余内容是后续实现的安全和验收基线。

## 1. 安全边界

NetRelay 能禁用网络适配器且始终以管理员权限运行，错误实现可能导致系统离线或扩大高权限攻击面。

必须遵循：

- 仅允许操作重新枚举后仍存在的接口 GUID。
- UI 输入、CLI 参数、配置文件和通知激活参数全部视为不可信。
- 不执行用户提供的 Shell、PowerShell、任意程序路径或任务参数。
- 任务计划程序中的动作固定指向当前安装目录的 NetRelay。
- 配置写入采用原子替换并保留最近有效备份。
- 自动禁用前验证备用互联网；执行后失败则立即回滚。
- 配置损坏、版本未知或校验失败时暂停自动化。
- 日志避免凭据、完整响应正文和不必要的个人网络信息。

## 2. 权限与通知风险

始终管理员运行简化了网卡控制和任务注册，但也意味着 WPF UI 处于高权限进程。

首版缓解措施：

- 应用服务采用最小权限和参数白名单。
- 禁止任意 Shell、PowerShell 和 URL 打开能力。
- 外部链接交给经过校验的系统浏览器入口。
- 设置严格内容安全策略，不加载远程脚本。
- 通知操作只携带短 ID，所有真实参数从本地配置重新解析。

长期建议：评估拆分普通权限 UI 与受限高权限辅助进程，缩小高权限攻击面。

## 3. 测试分层

| 层级 | 范围 | 要求 |
| --- | --- | --- |
| C# 单元测试 | 规则评估、连续失败、冷却、迁移、错误映射 | 不操作真实网卡 |
| 前端单元测试 | 页面状态、规则表单、危险操作确认 | 使用模拟命令 |
| 集成测试 | 配置、任务映射、CLI 参数、日志 | 使用临时目录和模拟 Windows 接口 |
| Windows 真机测试 | 网卡控制、通知、任务计划、休眠恢复 | 使用专用测试机 |
| 发布验收 | 安装、升级、卸载、签名、SmartScreen | Windows 10/11 x64 |

## 4. 核心验收矩阵

| 场景 | 预期结果 |
| --- | --- |
| 有线链路显示连接但双端点连续失败 | 识别为无互联网，不被链路状态误导 |
| 手机热点可联网 | 自动禁用校园网后复检互联网成功 |
| 手机热点已连接但无法联网 | 跳过自动禁用并发送通知 |
| 所有网络均断开 | 只通知，不自动禁用目标网卡 |
| 单次 HTTP 超时 | 不立即判定断网 |
| 网络快速反复变化 | 防抖且冷却期内不重复执行 |
| 目标网卡显示名称变化 | 规则仍通过 GUID 找到目标 |
| 目标网卡被删除 | 暂停相关规则并说明原因 |
| 目标网卡已经禁用 | 再次禁用视为幂等成功 |
| 主窗口关闭 | 时间规则和提前通知仍执行 |
| 托盘进程退出 | 时间规则执行，网络变化规则不执行并可被诊断 |
| 电脑休眠错过时间 | 在允许迟到窗口内执行，否则跳过并记录 |
| 通知选择延迟 | 只延迟本次，不修改规则 |
| 通知选择取消本次 | 执行入口跳过并记录取消 |
| 禁用后复检失败 | 立即尝试重新启用并通知 |
| 配置文件损坏 | 加载备份、暂停自动化、不执行未知规则 |
| 任务计划同步失败 | 规则显示未激活，不假装保存成功 |

## 5. 接口与数据测试

- 所有应用服务方法验证 GUID、UUID、范围、枚举值和权限。
- CLI 对未知参数、缺失值、超长值和注入字符返回失败。
- 配置迁移覆盖每个旧版本到当前版本。
- JSONL 日志在进程异常退出后仍能读取既有完整记录。
- 规则创建、修改和删除与任务计划项保持幂等一致。
- 时间按本地时区、夏令时变化和系统时间调整进行测试。

## 6. 已知限制

- 条件变化规则依赖托盘进程，托盘未运行时无法监听。
- 双端点均可能被地区网络、校园网、代理或防火墙屏蔽。
- 源 IP 绑定不一定足以控制 Windows 实际出口，必须验证实际接口。
- VPN、虚拟交换机和复杂路由环境可能影响备用网卡识别。
- 未签名的高权限程序会触发信任和分发问题。
- Windows 通知操作与高权限应用的激活兼容性尚未确认。
- 首版没有 Windows 服务，因此无法在用户未登录时监听网络变化。

## 7. 技术债与改进建议

按优先级：

1. 实现后评估普通权限 UI 与高权限辅助进程拆分。
2. 建立 Windows 10/11 多版本和多网卡真机测试环境。
3. 为复杂路由、VPN 和代理环境提供可解释的诊断视图。
4. 提供端点健康度统计，避免长期失效端点造成误判。
5. 评估应用签名、自动更新与更新签名验证。
6. 在用户明确同意后，考虑匿名崩溃报告；首版默认不上传遥测。

## 8. 未确认事项

- 网卡启用/禁用所采用的具体 Windows API 及其跨版本行为。
- Windows App SDK/WinRT 通知在非打包 WPF 管理员应用中的激活行为。
- Windows 任务计划程序在管理员应用、通知入口和不同登录状态下的最佳配置。
- 默认双端点在目标用户网络中的成功率、隐私接受度和响应稳定性。
- 复杂校园认证、透明代理和强制门户对主动探测的影响。
