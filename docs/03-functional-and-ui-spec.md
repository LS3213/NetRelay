# 功能与 UI 规格

[上一篇：架构与数据流](02-architecture-and-data-flow.md) | [返回索引](README.md) | [下一篇：接口与数据模型](04-interfaces-and-data-model.md)

> 当前已实现自动化管理 UI、执行历史面板、托盘气泡通知以及中央悬浮 Toast 操作提示。通知操作按钮、独立通知进程等增强能力尚未实现，具体边界以本文各功能状态说明为准。

## 1. 信息架构

| 页面 | 主要内容 |
| --- | --- |
| 概览 | 已实现网络摘要、目标网卡扫描与选择；快速启用/禁用和下一条规则待实现 |
| 网卡详情 | 全部网卡、GUID、类型、链路、IP、路由、探测状态 |
| 自动化规则 | 规则列表、创建/编辑、启停、立即试运行 |
| 执行历史 | 执行、跳过、失败、恢复和探测详情 |
| 设置 | 通知、主题、探测端点、日志、启动项和维护工具 |

窗口关闭默认最小化到托盘；托盘菜单提供打开主窗口、暂停自动化、快速恢复最近禁用网卡和退出。

## 2. 概览与快速操作

- 网卡卡片及详情显示友好名称、接口类型、启用状态、链路状态、互联网状态及最近探测时间。系统会在后台并发对列表中所有网卡进行连通性检测，保证所有网卡的状态能够实时且自动地得到更新，而不需要用户手动点击选中网卡才开始更新。此检测在程序启动初始化、切换当前选择网卡、手动点击刷新以及后台每 5 秒的定期检测中自动触发。同时，详情面板采用紧凑排边距和弹性滚动容器（ScrollViewer），确保在各种高度窗口下属性文字不会与下方的启用/禁用按钮发生遮挡或被裁剪。
- 网卡卡片显示实时收发速率和最近约 30 秒流量波形；波形来自 Windows/.NET 接口计数器采样，不抓取数据包内容。
- 网卡卡片显示启发式接口分类。由于 Windows 不为所有驱动提供可靠物理/虚拟标记，分类必须使用“物理候选”“疑似虚拟”等非绝对措辞。
- 用户显式选择目标网卡，配置中保存接口 GUID，而非显示名称。
- 启用操作可直接执行；禁用操作必须显示确认框。
- 确认框明确显示将受影响的网卡、当前默认路由和备用网络状态。
- 即使所有联网探测失败，手动启用/禁用仍可执行。
- 操作完成后刷新状态、写日志、发送 Windows 气泡通知并展示顶部中央 Toast 浮动提示通知。
- **操作反馈 (Toast 弹窗)**：网卡启用/禁用或规则手动执行等操作启动及完成后，会在程序中上部（避开标题栏）弹出磨砂玻璃样式的 Toast 浮动提示，并带有信息状态图标。该弹窗伴随平滑的滑动+淡入淡出动画，显示 2.5 秒后自动消失。弹窗为点击穿透设计（`IsHitTestVisible="False"`），出现时不影响对其下方控件的鼠标操作。

当前实现已包含启用/禁用、禁用确认、重复操作保护、界面结果反馈、默认路由与备用网络状态识别、持久日志、WPF毛玻璃倒计时悬浮窗口和顶部悬浮 Toast 弹窗通知。

禁用网卡不会从 NetRelay 列表消失：应用合并活动接口与 Windows 原生网络连接列表，并对仅存在于原生连接列表中的接口显示“已禁用”状态。

## 3. 自动化规则编辑

每条规则配置：

- 名称、启用状态、目标网卡、动作（启用或禁用）。
- 触发器：一次性、每日、每周指定日期或网络条件变化。
- 时间规则可选附加条件。
- 网络条件、连续失败阈值、防抖时间和冷却时间。
- 多个提前通知时间，例如 30、5、1 分钟。
- 本次执行允许的通知操作：打开程序、延迟、取消。
- 禁用后的可选自动恢复延迟。
- 自动禁用时必须使用的备用网络保护。

保存规则时写入本地配置并热重载内联调度器。规则不创建独立 Windows 任务；仅开机自启功能使用固定的 Windows 登录任务。

## 4. 通知行为

| 场景 | 示例信息 | 可用操作 |
| --- | --- | --- |
| 提前提醒 | 5 分钟后将禁用“以太网”，预计切换到“个人热点” | 打开、延迟、取消本次 |
| 即将执行 | 正在验证备用网络并准备切换 | 打开 |
| 成功 | 已禁用“以太网”，当前互联网经“个人热点”访问 | 打开、立即恢复 |
| 跳过 | 备用网络不可用，已跳过自动禁用 | 打开 |
| 失败 | 禁用失败，Windows 错误码：… | 打开、重试 |
| 自动恢复 | 已重新启用“以太网” | 打开 |

延迟和取消只影响本次执行，不修改规则本身。每次延迟或取消都必须写入执行历史。

当前实现使用系统托盘气泡发送提前提醒、自动执行成功、跳过、失败、回滚和恢复结果。点击气泡仅打开主窗口；通知内的延迟、取消、立即恢复和重试按钮属于后续设计，尚未实现。
探测配置无效时，启动阶段会发送“自动化已暂停”托盘气泡，并且调度器不会执行自动规则。

## 5. 液态玻璃视觉规范

所有主界面列表、弹窗表单和下拉列表使用像素级无级滚动，不按完整列表项跳动。鼠标滚轮滚动采用短时缓出动画，触控拖动使用 WPF 惯性参数；到达内层滚动区域边界后，滚轮事件可继续传递给外层滚动区域。

### 设计原则

- 背景使用低不透明度渐变与柔和色斑，不使用大面积高不透明度纯色。
- 外层卡片使用 24px 至 32px 连续圆角；内层组件按嵌套关系递减。
- 卡片采用 `backdrop-filter: blur(30px) saturate(180%)`。
- 亮色边框建议 `rgba(255,255,255,0.4)`；暗色边框建议 `rgba(255,255,255,0.12)`。
- 阴影至少包含近距离形体阴影和远距离弥散阴影。
- Hover、Active 和 Focus 使用 `cubic-bezier(0.25, 1, 0.5, 1)`，并提供轻微缩放与内部光晕。

计划样式令牌：

```css
:root {
  --glass-bg: rgba(255, 255, 255, 0.20);
  --glass-border: rgba(255, 255, 255, 0.40);
  --glass-radius-card: 28px;
  --glass-radius-control: 18px;
  --glass-blur: blur(30px) saturate(180%);
  --glass-shadow:
    0 2px 8px rgba(16, 24, 40, 0.12),
    0 24px 64px rgba(16, 24, 40, 0.18);
  --spring: cubic-bezier(0.25, 1, 0.5, 1);
}
```

### 可访问性与降级

- 支持亮色、暗色和跟随系统。
- Windows 关闭透明效果、DWM 不支持 Mica 或检测到低性能时，使用高可读性 WPF 半透明背景。
- 文本和状态不能只依赖颜色；使用图标、标签和说明共同表达。
- 支持键盘操作、可见焦点和 `prefers-reduced-motion`。
- 危险操作按钮使用明确文字，不以只有图标的控件替代。

### 选项卡导航与分段控件规范 (Segmented Control Specification)

为了在全透明/高不透明度高斯毛玻璃背景上获得优秀的对比度，同时保持物理拟物感，分段导航组件（如主界面上方 Tab 切换栏）遵循以下设计规范：

1. **还原干净通透底座轨道**：
   - 导航栏底座使用原生干净的 `GlassCardStyle` 底板（60% 不透明度白色渐变，1px 91% 不透明度高亮白边），不增加任何带有破坏性的色块背景，融入窗口整体高斯模糊质感。
2. **重塑玉润磨砂玻璃胶囊**：
   - 选中滑块采用**高浓度、低透明度磨砂渐变**（顶部 92% 亮白高光、中部 72% 水蓝色渐变 `#E2EEFF`、底部 30% 渐变白色），在浅色背景上表现出滋润、通透的玻璃玉石反光质感。
   - 边框采用恒定 `1.0` 描边厚度，防止由于厚度切换引起的文本 1 像素抖动，并使用高对比度 96% 纯白镜面高光，强化滑块边界折射。
3. **超轻量防脏漫反射阴影 (Anti-Muddy DropShadow)**：
   - 为了防止半透明玻璃组件由于阴影反向污染产生“发脏发灰”的视觉效果，选中阴影使用极低的不透明度（`Opacity = 8%`）与紧致的漫反射参数（`BlurRadius = 10`, `ShadowDepth = 1.2`），仅赋予微弱的物理浮起高度，保持高斯玻璃本身的干净。

### 扁平磨砂玻璃按钮与输入控件规范 (Glassmorphic Buttons and Input Controls Specification)

为了消除实体饱和色块与高斯毛玻璃窗口背景之间的突兀感，全程序的所有按钮及核心输入表单控件遵循以下设计规范：

1. **统一磨砂玻璃按钮设计 (Unified Glassmorphic Buttons)**：
   - 彻底废除实体色块（如原本纯蓝的保存按钮、纯红的禁用网卡按钮），使用基于半透明渐变、反射边缘、彩色外发光微阴影组合而成的毛玻璃效果：
     - **常规按钮 (`SoftButtonStyle`)**：白色反射玻璃。渐变填充（从顶部 `93%` 不透明白高光到底部 `18%` 半透白），配以折射白色边框（`27%` - `96%` 不透明）。按钮文字为深墨蓝品牌色（`#182236`）。
     - **主操作按钮 (`PrimaryButtonStyle`)**：蓝色磨砂玻璃。渐变填充（从顶部 `96%` 半透白到中部 `83%` 浅蓝到底部 `8%` 品牌蓝），搭配高光蓝色边框（`37%` - `97%` 不透明），深海主题蓝字（`#536EF2`）。Hover 激活蓝色柔和环境发光（`ShadowColor="#536EF2"`, `Opacity=0.12`）。
     - **危险操作按钮 (`DangerButtonStyle`)**：粉红磨砂玻璃。渐变填充（从顶部 `96%` 半透白到中部 `83%` 浅红到底部 `8%` 珊瑚红），搭配珊瑚红渐变边框，珊瑚红字（`#E85C63`）。Hover 激活红色柔和环境发光（`ShadowColor="#E85C63"`, `Opacity=0.12`）。
   - **WPF 隐式 TextBlock 穿透重载**：为了避免 WPF 全局隐式 TextBlock 样式强行覆盖 Button 自身的 Foreground，在所有 Button 样式的 `<Style.Resources>` 首位注入隐式 TextBlock 样式，将 `Foreground` 绑定到 `{Binding Foreground, RelativeSource={RelativeSource AncestorType=Button}}`，确保按钮内文字能够完全继承按钮的前景色属性，确保极佳的对比度与颜色统一性。
   - **恒定圆角与内缩 Hover 遮罩**：所有全局按钮边框的圆角统一固定为 `14px`。当鼠标悬停时，通过在边框内层放置 `Margin="-14,-9"`、`CornerRadius="13"` 的微缩叠加层（`HoverOverlay`）来提供深色/同色系微发光反馈，不破坏外层玻璃质感。

2. **全局输入与选项控件 (Global Form Inputs)**：
   - **复选框 (`CheckBox`)**：移除了传统 3D 棱角框，改用 18x18 像素、5px 圆角的超轻磨砂半透明底板。激活时平滑填充品牌蓝色 (`#536EF2`) 并显示亮白矢量勾。
   - **下拉选择框 (`ComboBox`)**：主按钮重载为 10px 圆角的白色半透磨砂玻璃容器，右侧辅以 Win11 Segoe Fluent 下拉指示箭头；弹出菜单 (`Popup`) 改为 12px 圆角、微乳白半透、附带深色漫反射阴影的高级卡片；下拉列表子项 (`ComboBoxItem`) 为 8px 圆角卡片，配合 Hover 淡蓝/激活深蓝样式，提供细腻的微交互。

## 6. 状态与空态

- 扫描中：显示骨架和当前扫描步骤。
- 没有网卡：解释可能原因并提供刷新。
- 目标网卡已移除：规则暂停，并要求重新绑定。
- 配置损坏：加载最后有效备份，提示用户查看诊断。
- 自动化暂停：所有页面和托盘均显示明显状态。
