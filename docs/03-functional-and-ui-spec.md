# 功能与 UI 规格

[上一篇：架构与数据流](02-architecture-and-data-flow.md) | [返回索引](README.md) | [下一篇：接口与数据模型](04-interfaces-and-data-model.md)

> 第一阶段已实现概览页面、网卡列表、刷新、选择和基础详情。自动化、通知、设置与其他交互仍为计划实现。

## 1. 信息架构

| 页面 | 主要内容 |
| --- | --- |
| 概览 | 已实现网络摘要、目标网卡扫描与选择；快速启用/禁用和下一条规则待实现 |
| 网卡详情 | 全部网卡、GUID、类型、链路、IP、路由、探测状态 |
| 自动化规则 | 规则列表、创建/编辑、启停、立即试运行 |
| 执行历史 | 执行、跳过、失败、恢复和探测详情 |
| 设置 | 通知、主题、探测端点、日志、启动项和维护工具 |

窗口关闭默认最小化到托盘；托盘菜单提供打开主窗口、暂停自动化、快速恢复最近禁用网卡和退出。

## 2. 概览与快速操作

- 网卡卡片显示友好名称、接口类型、启用状态、链路状态、互联网状态及最近探测时间。
- 用户显式选择目标网卡，配置中保存接口 GUID，而非显示名称。
- 启用操作可直接执行；禁用操作必须显示确认框。
- 确认框明确显示将受影响的网卡、当前默认路由和备用网络状态。
- 即使所有联网探测失败，手动启用/禁用仍可执行。
- 操作完成后刷新状态、写日志并发送 Windows 通知。

## 3. 自动化规则编辑

每条规则配置：

- 名称、启用状态、目标网卡、动作（启用或禁用）。
- 触发器：一次性、每日、每周指定日期或网络条件变化。
- 时间规则可选附加条件。
- 网络条件、连续失败阈值、防抖时间和冷却时间。
- 多个提前通知时间，例如 30、5、1 分钟。
- 本次执行允许的通知操作：打开程序、延迟、取消。
- 禁用后的可选自动恢复延迟。
- 自动禁用时必须使用的备用网络保护。

保存时间规则时，先校验配置，再同步任务计划；同步失败则规则保持“未激活”并显示原因，不能假装保存成功。

## 4. 通知行为

| 场景 | 示例信息 | 可用操作 |
| --- | --- | --- |
| 提前提醒 | 5 分钟后将禁用“以太网”，预计切换到“个人热点” | 打开、延迟、取消本次 |
| 即将执行 | 正在验证备用网络并准备切换 | 打开 |
| 成功 | 已禁用“以太网”，当前互联网经“个人热点”访问 | 打开、立即恢复 |
| 跳过 | 备用网络不可用，已跳过自动禁用 | 打开 |
| 失败 | 禁用失败，Windows 错误码：… | 打开、重试 |
| 自动恢复 | 已重新启用“以太网” | 打开 |

延迟和取消只影响本次执行，不修改规则本身。每次延迟或取消都必须写入执行历史。

**未确认：** Windows 通知按钮直接激活始终管理员运行的应用时，是否能在所有目标系统上稳定工作。若不稳定，通知按钮降级为打开主程序，由主程序完成操作。

## 5. 液态玻璃视觉规范

### 设计原则

- 背景使用低不透明度渐变与柔和色斑，不使用大面积高不透明度纯色。
- 外层卡片使用 24px 至 32px 连续圆角；内层组件按嵌套关系递减。
- 卡片采用 `backdrop-filter: blur(30px) saturate(180%)`。
- 亮色边框建议 `rgba(255,255,255,0.4)`；暗色边框建议 `rgba(255,255,255,0.12)`。
- 阴影至少包含近距离形体阴影和远距离弥散阴影。
- Hover、Active 和 Focus 使用 `cubic-bezier(0.25, 1, 0.5, 1)`，并提供轻微缩放与内部光晕。

计划样式令牌：

```css
:root {
  --glass-bg: rgba(255, 255, 255, 0.20);
  --glass-border: rgba(255, 255, 255, 0.40);
  --glass-radius-card: 28px;
  --glass-radius-control: 18px;
  --glass-blur: blur(30px) saturate(180%);
  --glass-shadow:
    0 2px 8px rgba(16, 24, 40, 0.12),
    0 24px 64px rgba(16, 24, 40, 0.18);
  --spring: cubic-bezier(0.25, 1, 0.5, 1);
}
```

### 可访问性与降级

- 支持亮色、暗色和跟随系统。
- Windows 关闭透明效果、DWM 不支持 Mica 或检测到低性能时，使用高可读性 WPF 半透明背景。
- 文本和状态不能只依赖颜色；使用图标、标签和说明共同表达。
- 支持键盘操作、可见焦点和 `prefers-reduced-motion`。
- 危险操作按钮使用明确文字，不以只有图标的控件替代。

## 6. 状态与空态

- 扫描中：显示骨架和当前扫描步骤。
- 没有网卡：解释可能原因并提供刷新。
- 目标网卡已移除：规则暂停，并要求重新绑定。
- 配置损坏：加载最后有效备份，提示用户查看诊断。
- 自动化暂停：所有页面和托盘均显示明显状态。
